# 이 폴더에 대하여 (Claude Code 자동 로드)

**희림종합건축사사무소**의 B2B 홍보·자사 브랜딩용 **콘텐츠 파이프라인**입니다.
건축 전문성을 보여주는 정보 콘텐츠(블로그·유튜브)를 만들기 위해,
매주 국내외 건축 트렌드·뉴스를 수집 → 신뢰도 필터링 → 노션 기록 → 주제 선별 → 원고 제작을 자동화합니다.

사용자는 터미널·코딩을 거의 다루지 않습니다. 짧게 지시해도 아래 규칙대로 수행하세요.

## 파이프라인 (매주)

```
1. weekly-scan   국내외 건축 트렌드·뉴스 스크리닝 + 신뢰도 필터
2. notion-log    선별된 이슈를 노션 DB에 기록
3. topic-selection  기록된 이슈 → 블로그/유튜브 주제 후보 + 우선순위
4. blog-draft / youtube-script  선택된 주제 → 완성 원고
```

전체 순서는 `workflows/weekly-pipeline.md` 참조.

## 폴더 역할

| 폴더 | 역할 |
|------|------|
| `prompts/` | 각 단계 실행 지침. 사용자가 "이번 주 스캔 돌려줘" 하면 해당 파일 절차대로 수행 |
| `templates/` | 결과물 형식 (이슈 카드, 주간 다이제스트, 블로그 원고, 유튜브 대본) |
| `workflows/` | 여러 단계를 묶은 전체 절차 |
| `reference/` | 고정 정보. **작업 전 반드시 관련 파일을 읽고 반영**: 희림 브랜드, 타깃 독자, 신뢰 소스, 신뢰도 기준 |
| `inputs/` | 사용자가 넣어둔 자료 (참고 링크 목록, 지난 콘텐츠 등) |
| `outputs/` | 완성물 저장. `outputs/YYYY-MM-DD-작업이름.md` |

## 기본 규칙 (항상 적용)

1. **언어**: 결과물 본문은 **한국어**. 해외 자료는 원문 링크 + 한국어 요약 병기.
2. **신뢰도 우선**: 출처가 불분명하거나 1차 확인이 안 되는 정보는 콘텐츠에 넣지 않는다. 판단 기준은 `reference/credibility-criteria.md`.
3. **출처 필수**: 모든 이슈·주장에 원문 링크와 발행일을 명시. 추측과 사실을 구분 표기.
4. **브랜드 톤**: `reference/heerim-brand.md`의 톤&매너를 따른다. 핵심은 **중립 해설체 + 자사(희림) 언급 최소**(편당 1~2회, 없어도 무방). 홍보가 아니라 관점·정보가 주인공. 축은 건물 유형이 아니라 **업무(설계·CM·감리)**.
5. **타깃**: 독자는 동종 건축인(우선) + 건축 관심 일반대중. 전문 용어는 쉽게 풀되 깊이는 유지. `reference/audience.md` 참고.
6. **저장**: 완성물은 `outputs/`에 오늘 날짜를 붙여 저장.
7. **노션 기록**: Notion MCP 사용. 허브 「희림 콘텐츠 파이프라인」 아래 3개 DB — `건축 이슈 수집` / `콘텐츠 원고` / `주간 다이제스트`. 구조·data_source_id는 `reference/notion-setup.md`. 연동 안 됐으면 임시로 `outputs/`에 표로 저장하고 알림.
8. **작업 후**: 해당 prompts 파일의 품질 체크리스트를 스스로 확인하고 결과 하단에 남긴다.
