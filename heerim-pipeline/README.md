# 희림 콘텐츠 파이프라인 — 사용 설명서

코딩을 몰라도 됩니다. **Claude Code에 한국어로 말만 하면** 됩니다.

## 매주 하는 일

Claude Code 창에 순서대로 입력하세요:

1. `이번 주 건축 이슈 스캔해줘`
   → 국내외 트렌드·뉴스를 훑고 신뢰도 높은 것만 추려 `outputs/`에 주간 다이제스트로 저장
2. `노션에 기록해줘`
   → 선별된 이슈를 노션 DB에 카드로 추가 (연동돼 있을 때)
3. `이번 주 콘텐츠 주제 뽑아줘`
   → 블로그/유튜브 주제 후보 + 우선순위 제시
4. `"○○" 주제로 블로그 원고 써줘` / `"○○" 유튜브 대본 써줘`
   → 완성 원고 초안 생성

또는 한 번에: `이번 주 파이프라인 돌려줘` (1~3단계 자동 진행)

## 폴더 안내

| 폴더 | 무엇 |
|------|------|
| `prompts/` | 단계별 지침 — 문구를 직접 다듬어도 됨 |
| `templates/` | 결과물 서식 (이슈 카드 / 주간 다이제스트 / 블로그 / 유튜브) |
| `reference/` | ⭐ 먼저 채우는 곳: 희림 브랜드, 타깃 독자, 신뢰 소스, 신뢰도 기준, 노션 설정 |
| `inputs/` | 참고 자료 넣는 곳 (지난 콘텐츠, 링크 목록 등) |
| `outputs/` | 완성물 저장 (`YYYY-MM-DD-이름.md`) |
