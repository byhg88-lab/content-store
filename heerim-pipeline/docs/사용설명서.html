4. 매주 하는 일

자동으로 되는 것 (월요일 오전 10시)

  1. 지난 7일 국내외 건축 이슈를 훑고, 신뢰도 낮은 것은 버림 → 주간 다이제스트 저장
  2. 남은 이슈를 노션 건축 이슈 수집에 추가(중복 제외), 주간 다이제스트에 로그 1행
  3. "신규" 이슈를 점수화해 블로그 2 · 유튜브 1 주제 추천 → 주제선정 파일 저장, 선정 이슈는 "제작예정"으로

PC가 그 시각 꺼져 있었으면 다음에 켜서 로그인한 뒤 자동으로 따라잡아 실행됩니다.

사람이 하는 것

  1. 월요일 중: outputs/날짜-주제선정.md 를 열어 추천 주제 확인. 마음에 들면 그대로, 아니면 다른 이슈로 교체
  2. 원고 지시: Claude Code에 "○○" 블로그 써줘 / "○○" 유튜브 대본 써줘
  3. 검토: outputs/ 초안과 노션 콘텐츠 원고 행을 확인. 고칠 점을 그대로 말하면 Claude가 수정
  4. 발행 후: 노션에서 그 원고 상태를 "발행완료"로, 대상 이슈를 "제작완료"로 변경 (Claude에게 부탁해도 됨)
주 1회, 이번 주 주제 확정: 1번과 3번으로 갈게. 둘 다 원고 써줘 처럼 한 번에 지시해도 됩니다.

6. 자동 실행 설정과 관리

스크립트 3종이 함께 있어야 합니다: scripts/register-task.ps1(등록용) · scripts/run-weekly.ps1(실행 러너) · scripts/weekly-prompt.txt(한국어 지시문).

등록 (한 번만)

  1. 시작 메뉴 → PowerShell → 오른쪽 클릭 → 관리자 권한으로 실행
  2. 아래 붙여넣고 Enter
powershell -NoProfile -ExecutionPolicy Bypass -File "c:\Users\hahahoho\Desktop\content\scripts\register-task.ps1"

Registered: Heerim Weekly Pipeline 과 다음 실행 시각이 나오면 완료.

테스트 / 확인 / 해제

schtasks /run   /tn "Heerim Weekly Pipeline"       # 지금 바로 한 번 실행
schtasks /query /tn "Heerim Weekly Pipeline"       # 등록 상태 보기
schtasks /delete /tn "Heerim Weekly Pipeline" /f   # 자동 실행 해제

시간 바꾸기

scripts/register-task.ps1 안의 -At 10:00am 을 원하는 시각으로 고친 뒤, 위 등록 명령을 다시 실행합니다.

실행 로그

outputs/_logs/weekly-날짜.log — 매 실행마다 생성. 끝에 exit code 0 이면 정상.

7. 문제 해결

증상원인 / 해결
자동 실행이 노션 기록에서 멈춤노션 로그인 만료. Claude Code에서 /mcp → notion → Authenticate 재인증
월요일에 안 돌았음그 시각 PC가 꺼져 있었음. 켜고 로그인하면 자동 따라잡기. 안 되면 schtasks /run 으로 수동 실행
PowerShell에서 "예기치 않은 토큰" 오류.ps1 파일에 한글이 들어가면 발생. 스크립트에는 한글을 넣지 말고 weekly-prompt.txt 에만 둘 것
스캔 결과에 신규 이슈가 적음정상일 수 있음. 그 주는 진행 중 이슈를 포함해 채움. 신뢰도 '하'는 원래 제외됨
노션에 테스트/오류 행이 남음MCP에는 삭제 기능이 없음. 노션에서 해당 행 우클릭 → 삭제
결과 톤·방향이 이상함Claude에게 그대로 지적 → 해당 prompts/ 또는 reference/ 파일이 수정됨

9. 시스템 고치기 (커스터마이징)

  • 가장 쉬운 방법: 결과를 보고 Claude Code에 불만·요청을 그대로 말하면, 해당 prompts/ 파일을 고쳐 다음 실행부터 반영합니다.
  • 직접 편집: prompts/*.md 를 메모장으로 열어 문구를 바꿔도 됩니다. 형식은 자유롭게, "절차"와 "품질 체크리스트" 항목만 유지하세요.
  • reference 채우기: heerim-brand.md 의 슬로건·예시 칸, sources.md 의 자주 보는 매체를 채울수록 스캔·원고가 정확해집니다.
  • 지난 콘텐츠 목록: 이미 발행한 글·영상 제목을 inputs/ 에 텍스트로 넣어두면 주제 선별 때 중복을 피합니다.
