# 프롬프트: 노션에 이슈 기록

## 목적
주간 다이제스트에서 선별된 이슈를 노션 `건축 이슈 수집` DB에 카드로 추가하고,
`주간 다이제스트` DB에 이번 주 로그 1행을 남긴다.

## 필요한 입력
- 대상 주간 다이제스트 파일 (기본: `outputs/`의 최신 `*-주간다이제스트.md`)
- 노션 연동 상태 (연결 정보·data_source_id는 `reference/notion-setup.md`)

## 절차
1. `reference/notion-setup.md`(매핑 규칙)와 `reference/notion-setup.local.md`(실제 data_source_id)를 읽는다.
   - 건축 이슈 수집 / 주간 다이제스트 의 data_source_id는 local 파일 참조
2. **중복 체크**: 건축 이슈 수집 DB를 조회해 기존 `원문` URL 목록을 가져온다.
3. 다이제스트의 각 이슈를 아래로 매핑해 페이지 생성 (URL이 이미 있으면 스킵):
   - 제목→제목 / 한 줄 요약→요약 / 카테고리→분류 / 국내·해외→지역 /
     발행일→발행일 / 원문 링크→원문 / 신뢰도→신뢰도 / 콘텐츠 각도→콘텐츠 각도
   - (고정) 상태 = "신규", 수집일 = 실행일
   - 분류 값은 5개 중 하나로 정규화: 설계·디자인 / 기술·공법 / 프로젝트·수주 / 제도·법규 / 업계동향
     (다이제스트의 "발주·사업관리·CM/감리"는 → 제도·법규)
4. `주간 다이제스트` DB에 1행 추가:
   - 제목 = "YYYY-MM-DD 주간 (스캔 기간)" / 주간 시작일 = 그 주 월요일 /
     이슈 수 = 통과 이슈 개수 / 유망 주제 3 = 다이제스트의 "유망 3개" 요약 / 로컬 파일 = outputs 경로
5. 추가·스킵 결과를 표로 보고한다 (이슈 추가 N건 / 중복 스킵 M건 / 다이제스트 로그 1건).
6. 연동이 안 돼 있으면: 노션에 붙여넣기 좋은 표를 `outputs/YYYY-MM-DD-노션기록.md`로 저장하고 알린다.

## 품질 체크리스트
- [ ] 모든 이슈가 추가되거나, 스킵 사유(중복)가 명시됐다
- [ ] 링크·발행일이 정확히 들어갔다
- [ ] 이슈 상태값이 "신규"로 설정됐다
- [ ] 주간 다이제스트 DB에 이번 주 로그 1행이 생겼다
