# 프롬프트: 콘텐츠 주제 선별

## 목적
축적된 이슈(노션 DB 또는 주간 다이제스트)에서 이번에 만들 **블로그/유튜브 주제**를 골라
우선순위와 제작 방향을 제시한다.

## 필요한 입력
- 소스: 노션 DB의 "신규" 상태 이슈 (연동 시) 또는 최신 주간 다이제스트
- 이번 주 제작 편수 (기본: 블로그 2, 유튜브 1)
- 이미 다룬 주제 (선택 — `inputs/`의 지난 콘텐츠 목록 참고)

## 절차
1. `reference/heerim-brand.md`, `reference/audience.md`를 읽는다.
2. 후보 이슈를 아래 기준으로 점수화한다 (각 1~5):
   - **전문성 부합**: 희림 업무 영역(설계·CM·감리)·특화 유형과 연결해 전문 해설이 가능한가
   - **독자 관심**: 동종 건축인(우선) + 관심 일반대중이 클릭할 만한가
   - **시의성**: 지금 다뤄야 신선한가
   - **콘텐츠화 용이성**: 자료·사례·이미지 확보가 쉬운가
   - **차별성**: 다른 곳이 안 다룬 각도가 있는가
3. 상위 주제를 블로그용/유튜브용으로 배정한다 (유튜브는 시각적으로 풀기 좋은 것).
4. 각 선정 주제에 대해:
   - 제목안 2~3개 / 핵심 메시지 1줄 / 다룰 소제목 3~5개 / 필요한 자료·사례 / 예상 분량 / 참고 이슈 링크
   - 서술 방향은 **중립 해설체, 자사 언급 최소** (희림은 사례로 필요할 때만)
5. 탈락 주제는 이유를 한 줄씩. "다음에 다룰 후보"로 2~3개 보류 표시.
6. `outputs/YYYY-MM-DD-주제선정.md`로 저장. (노션 연동 시 선정된 이슈 상태를 "제작예정"으로 업데이트)

## 품질 체크리스트
- [ ] 선정 주제마다 점수 근거가 있다
- [ ] 제목안이 낚시성이 아니라 내용을 정확히 반영한다
- [ ] 유튜브 주제는 시각화가 가능한 소재다
- [ ] 이미 다룬 주제와 중복되지 않는다
- [ ] 각 주제에 참고 이슈 원문 링크가 연결됐다
