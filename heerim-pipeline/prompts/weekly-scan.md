# 프롬프트: 주간 건축 이슈 스캔

## 목적
지난 한 주(기본 7일) 국내외 건축 트렌드·뉴스·프로젝트 소식을 훑고, **신뢰도 높은 이슈만** 추려
한국어 주간 다이제스트를 만든다. 이후 노션 기록·주제 선별의 입력이 된다.

## 언제 쓰나
매주 정해진 요일 (권장: 월요일 오전).

## 필요한 입력
- 스캔 기간 (기본: 최근 7일)
- 중점 영역 (선택) — 비우면 `reference/heerim-brand.md`의 전문 영역(업무 기반: 설계·CM·감리)을 기준으로
- 제외할 주제 (선택)

## 절차
1. `reference/sources.md`(신뢰 소스), `reference/credibility-criteria.md`(신뢰도 기준),
   `reference/heerim-brand.md`(전문 영역·톤), `reference/audience.md`를 읽는다.
2. 웹 검색으로 아래 카테고리를 훑는다. **국내외 균형** (국내·해외 비슷한 수, 해외 최소 3건):
   - 설계·디자인 트렌드 (형태, 재료, 파사드, 공간 프로그램)
   - 기술·공법 (모듈러, 매스팀버, 3D프린팅, BIM/디지털, 친환경·탄소)
   - 발주·사업관리·CM/감리 제도 및 실무 동향 (발주 방식, 사업비·공정·품질관리, 감리 제도)
   - 주요 프로젝트·수주·준공·공모전 결과 (특히 희림 업무 영역(설계·CM·감리)과 특화 유형(공항·스포츠·의료)에 닿는 이슈)
   - 제도·법규 변화 (가볍게 — 큰 변화만)
   - 업계 동향 (M&A, 인력, 해외시장, 발주처 움직임)
3. 각 후보 이슈를 신뢰도 기준으로 평가한다. **기준 미달(출처 불명, 1차 확인 불가, 광고성)은 버린다.**
4. 통과한 이슈를 `templates/weekly-digest.md` 형식으로 정리한다. 이슈당:
   - 제목 / 한 줄 요약 / 카테고리 / 발행일 / 원문 링크 / 출처 신뢰도(상·중) /
   - 콘텐츠 각도(이 이슈로 다룰 수 있는 이야기 각도 — 설계·CM·감리 등 업무 관점, 회사 홍보 아님, 1~2줄) / 국내·해외 구분
5. 이슈는 8~15개 목표. 마지막에 **"이번 주 콘텐츠로 가장 유망한 3개"**를 별도 표시.
6. `outputs/YYYY-MM-DD-주간다이제스트.md`로 저장.

## 출력 형태
- 템플릿: `templates/weekly-digest.md`
- 저장 위치: `outputs/YYYY-MM-DD-주간다이제스트.md`

## 품질 체크리스트
- [ ] 모든 이슈에 원문 링크 + 발행일이 있다
- [ ] 해외 이슈가 최소 3건 포함됐다
- [ ] 신뢰도 '하'로 평가된 항목은 제외했다 (제외 사유를 하단에 간단 기록)
- [ ] 각 이슈에 "콘텐츠 각도"가 업무 관점(설계·CM·감리 등)으로 채워졌다 (회사 홍보성 표현 없음)
- [ ] 국내·해외 이슈 수가 비슷하다
- [ ] 희림 업무 영역·특화 유형과 연결되는 이슈가 우선 배치됐다
- [ ] 추측/미확인 정보는 [미확인]으로 표기
