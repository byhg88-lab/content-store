# 프롬프트: 유튜브 대본 작성

## 목적
선정된 주제로 희림 유튜브 영상의 **완성 대본 + 구성안**을 한국어로 작성한다.

## 필요한 입력
- 주제
- 참고 이슈 링크
- 영상 길이 (기본: 6~10분 / 숏폼이면 45~60초로 별도 지시)
- 진행 형식 (기본: 내레이션 + 자료화면. 인터뷰/출연자 있으면 명시)

## 절차
1. `reference/heerim-brand.md`, `reference/audience.md`를 읽는다. 톤은 **중립 해설체, 자사 언급 최소**.
2. 참고 링크 사실 확인.
3. `templates/youtube-script.md` 구조로 작성:
   - 훅(0~15초): 궁금증/장면 제시  → 주제 소개 → 본론 3~4개 세그먼트 → 건축적 인사이트 →
     실무 관점·심화 해석(희림 사례는 필요할 때만 1~2회) → 마무리 + 구독 유도
4. 대본은 **말하는 문장체**로. 세그먼트마다 `[화면: …]`, `[자막: …]`, `[B-roll: …]` 지시 병기.
5. 팩트는 대본 옆 주석으로 출처를 남긴다.
6. 하단 메타: 제목안 3개 / 썸네일 문구 2개 / 영상 설명란(설명 + 출처 링크 + 챕터 타임코드) / 태그.
7. `outputs/YYYY-MM-DD-유튜브-<주제슬러그>.md`로 저장.
8. **노션 `콘텐츠 원고` DB에 1행 추가** (data_source_id는 `reference/notion-setup.local.md` 참조):
   - 제목 = 확정 제목 / 유형 = "유튜브" / 상태 = "초안" / 작성일 = 오늘 / 로컬 파일 = outputs 경로
   - 대상 이슈 = 참고한 `건축 이슈 수집` 행 연결, 대본 본문을 그 행의 페이지 본문에 넣는다
   - 참고한 이슈 행의 상태를 "제작완료"로 변경
   - 연동 안 되면 건너뛰고 사용자에게 알림

## 출력 형태
- 템플릿: `templates/youtube-script.md`
- 저장 위치: `outputs/YYYY-MM-DD-유튜브-<주제슬러그>.md` + 노션 `콘텐츠 원고` DB

## 품질 체크리스트
- [ ] 첫 15초 훅이 명확하다
- [ ] 화면/자막/B-roll 지시가 세그먼트마다 있다
- [ ] 문장이 낭독하기 자연스럽다 (긴 수식어·번역투 없음)
- [ ] 사실 주장에 출처 주석이 있다
- [ ] 희림 언급이 1~2회 또는 없음, 억지 연결이 아니다
- [ ] 챕터 타임코드가 설명란에 있다
- [ ] 노션 `콘텐츠 원고` DB에 행이 생기고 본문이 들어갔다 (연동 시)
