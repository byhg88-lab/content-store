# 타깃 독자

> 브랜딩 1순위가 "업계 내 전문성 신뢰"이므로 **1차 독자(건축인)를 우선**으로 쓴다.
> 2차 독자(일반대중)는 글이 어렵지 않게 만드는 이해도 확보용.

## 1차 독자 — 동종 업계 / 건축인 (우선)
- 건축사, 설계사무소 실무자, 건축과 학생·취준생, 시공·엔지니어링·CM/감리 종사자
- 관심사: 새로운 설계 접근, 기술·공법, 국내외 프로젝트 사례, **설계·CM·감리 실무 관점,
  발주·사업관리 프로세스**, 업계 동향, 커리어
- 기대: 정보의 정확성과 깊이. 얕은 요약글은 안 읽음.
- 콘텐츠 함의: 도면·다이어그램·디테일·업무 프로세스 언급 OK, 전문 용어 써도 되지만 남용 금지

## 2차 독자 — 건축에 관심 있는 일반대중
- 공간·도시·디자인에 관심, 부동산/개발 뉴스 소비층, 잠재 발주처 실무자
- 관심사: "이 건물 왜 이렇게 생겼나", 도시 변화, 유명 프로젝트 뒷이야기
- 기대: 쉽게 설명해주는 것. 그림·사진 중요.
- 콘텐츠 함의: 전문 용어는 첫 등장 시 풀이, 스토리텔링 강조

## 두 독자를 한 콘텐츠에서 잡는 법
- 본문은 일반대중도 읽히게 쓰되, 한 단계 깊은 해석·디테일·실무 포인트를 소제목/박스로 덧붙여
  전문 독자도 만족시킨다.
- 제목은 대중적 호기심, 내용은 전문성.

## 하지 말 것
- 특정 발주처·경쟁사 저격
- 정치적 해석, 부동산 투자 조언
- 내부 미공개 프로젝트 정보 노출
