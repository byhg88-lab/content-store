# 신뢰도 판단 기준 (주간 스캔의 선별 필터)

이슈를 콘텐츠 소재로 채택할지 판단하는 기준. **'하'는 무조건 제외.**

## 신뢰도 등급

### 상 (바로 사용 가능)
- 1차 출처가 명확: 기관 발표, 설계사·발주처 공식 자료, 학술·협회 자료, 당사자 인터뷰
- 또는 신뢰도 높은 매체(Dezeen, 건축신문, SPACE 등)가 자체 취재로 보도
- 발행일 명시, 6개월 이내(트렌드성은 12개월)
- 사실·수치가 최소 2곳에서 교차 확인됨

### 중 (교차 확인 후 사용)
- 신뢰 매체 보도지만 단일 출처
- 1차 자료를 인용했으나 원문 링크는 없음 → 원문을 찾아 확인되면 '상'으로 승급
- 발행 3~12개월

### 하 (제외)
- 출처 불명, 커뮤니티·SNS 루머, 작성자·발행일 불명
- 홍보·광고성 (자재사·시공사 보도자료 원문 그대로)
- 확인 불가능한 수치·랭킹 ("세계 최고", "국내 유일" 등 근거 없음)
- 2년 이상 지난 내용을 신규처럼 유통

## 추가 체크
- **이해충돌**: 정보 제공자가 홍보 이해관계가 있으면 사실만 취하고 평가·전망은 배제
- **번역 왜곡**: 해외 기사는 원문을 확인해 오역·과장 여부 점검
- **AI 생성 의심**: 구체 지명·수치·인용이 없고 일반론만 반복하는 글은 배제

## 표기 규칙
- 콘텐츠에 쓸 때: 사실 = 그대로 / 추정·전망 = "~로 보인다", [미확인] 태그
- 다이제스트의 '제외된 후보'에 제외 사유를 한 줄로 남길 것
