# 워크플로우: 주간 콘텐츠 파이프라인

**매주 월요일 오전 자동 실행** (클라우드 스케줄). "이번 주 파이프라인 돌려줘"로 수동 실행도 가능.
자동 실행은 1~3단계까지 수행하고 결과를 요약 보고한다. 4단계(원고)는 사용자가 주제를 확정한 뒤 진행.

## 사전 조건
- `reference/` 파일이 채워져 있을 것 (heerim-brand, audience, sources, credibility-criteria)
- 노션 연동 완료 — 구조·ID는 `reference/notion-setup.md` (허브 아래 3개 DB)

## 단계

### 1. 스캔  →  `prompts/weekly-scan.md`
- 최근 7일 국내외 건축 이슈 수집 + 신뢰도 필터 (국내·해외 비슷한 수)
- 산출: `outputs/YYYY-MM-DD-주간다이제스트.md`
- 완료 후 "유망 3개"를 사용자에게 요약 보고

### 2. 노션 기록  →  `prompts/notion-log.md`
- 1의 결과를 `건축 이슈 수집` DB에 추가 (원문 URL 중복 제외)
- `주간 다이제스트` DB에 이번 주 로그 1행 추가
- 산출: 노션 페이지들 + 추가/스킵 요약

### 3. 주제 선별  →  `prompts/topic-selection.md`
- `건축 이슈 수집`의 "신규" 이슈를 점수화해 이번 주 주제 선정 (블로그 2 / 유튜브 1)
- 선정 이슈 상태를 "제작예정"으로 변경
- 산출: `outputs/YYYY-MM-DD-주제선정.md`
- **여기서 멈추고 사용자에게 주제 확정을 요청** (자동 실행도 여기까지)

### 4. 원고 제작  →  `prompts/blog-draft.md` / `prompts/youtube-script.md`  (사용자 확정 후 수동)
- 주제별 완성 원고 초안 작성
- `콘텐츠 원고` DB에 행 추가(상태 "초안", 본문 포함), 참고 이슈 상태를 "제작완료"로 변경
- 산출: `outputs/YYYY-MM-DD-블로그-*.md`, `outputs/YYYY-MM-DD-유튜브-*.md`

## 완료 체크리스트
- [ ] 주간 다이제스트 저장됨 (국내·해외 균형, 해외 3건 이상)
- [ ] `건축 이슈 수집`에 신규 이슈 반영 + `주간 다이제스트`에 로그 1행 (또는 md 대체본 + 사유)
- [ ] 주제선정 문서에 우선순위·근거 포함, 선정 이슈 "제작예정"
- [ ] 사용자 주제 확정 후에만 원고 단계 진행

## 자동 실행 안내
- 스케줄: 매주 월요일 오전 (클라우드 라우틴). 실행 로그·결과는 `/schedule` 로 확인.
- 자동 실행이 끝나면 다이제스트와 주제선정 요약이 남는다. 사용자는 주제를 확정하고
  `"<주제>" 블로그 써줘` / `"<주제>" 유튜브 대본 써줘` 로 4단계를 진행한다.
